# BelleWall 1.0.2

Symbian Belle 竖屏动态壁纸正式版。一个 SISX 内含 BelleWall、原生播放进程和桌面渲染注入器，三个组件同为 1.0.2。最低 Qt 运行库版本为编译版本 4.7.4；设备仍需满足 Symbian 的安装签名和权限要求。

## 更新

- 兼容已静态核验的 Nokia 603 FP2、E7 固件布局；未知 Belle 固件通过唯一的代码结构匹配推导背景对象位置，无法安全匹配时拒绝启动。所有机型使用同一个安装包。
- 视频 SYWP 可用 180×320 或 360×640，按素材时间请求最高 30 fps；内附 PC 制作工具支持导出 20／30 fps 测试素材。网页壁纸仍约 10 fps。
- 导入壁纸副本时可选择 C、E 或 F 盘；旧版保存在 C 盘的内容继续可读。
- PC 工具 ZIP 内含 Windows x64 FFmpeg 及其对应源码、构建说明和许可文件，仍需 Node.js。

## 验证与限制

组合 SISX 已完成签名、版本、组件顺序、依赖、解包载荷和哈希校验。用户反馈 E7 上 1.0.2 测试效果很好，但未提供持续帧率或逐项日志；603 的本轮视频与多盘测试尚待反馈。E7 切换到横屏时壁纸会崩溃，请保持竖屏使用。E6 等非标准屏当前不支持，程序与 PC 工具当前以中文为主。30 fps 是请求上限，并非实测刷新率。

安装前在旧版中点“停止并恢复桌面”，确认恢复后再更新。运行时要求原生默认黑色桌面背景。若启动被拒绝，请导出本地诊断，不要删除恢复记录。详细安装步骤见 [安装说明](INSTALL.md)，后续修复顺序见 [下一阶段计划](NEXT-PHASE-PLAN.md)。

正式附件：`BelleWall-1.0.2.sisx`、`BelleWall-1.0.2-tools.zip` 和 `SHA256SUMS.txt`。`dist/test/` 下的候选 ZIP 不属于正式 Release。
