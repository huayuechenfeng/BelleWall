# 安装、更新与卸载

下载 `BelleWall-1.0.0.sisx`。这是签名 SIS 安装包，依次包含 Renderer Helper、Native 和 BelleWall 三个组件，版本均为 1.0.0。选择 C 盘安装。设备需事先具备 Qt 4.8.1 及所需系统权限；安装包不捆绑 Qt，也不会绕过平台的证书／权限检查。

更新前在旧版点“停止并恢复桌面”，确认恢复，再正常退出。不要在壁纸运行或尚有恢复记录时更新。已有组件使用相同 UID 升级，不要混用不同版本的三个组件。

安装后打开 BelleWall，在壁纸管理导入 `.sywp`，先预览，再点“启动动态壁纸”。导入和选中不等于启动。第一次使用建议选 60 秒检查，准备阶段等待自动切页完成。

停止：从应用菜单重新打开 BelleWall，点“停止并恢复桌面”。出现未完成提示时保持解锁回桌面，再重试恢复。不要手动删除恢复记录。诊断可在“运行诊断”内导出到本地，不自动上传。

卸载：先停止／恢复，再执行“卸载准备”，成功后正常退出。到系统应用管理移除 BelleWall 1.0 安装项及残留的 BelleWall、BelleWall Native、BelleWall Renderer Helper 组件（若系统已连同组件移除，则不需重复）。旧 Preview 名称可能出现在升级前设备上。不要卸载 Qt 或删除自制源素材。

开发自签名不等于被所有设备信任，证书或权限失败请保留错误提示。范围与验证差异见 [兼容性](COMPATIBILITY.md)。
