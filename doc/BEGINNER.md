# 新手教程：不写代码制作动态壁纸

## 1. 准备工具

下载 Release 的 `BelleWall-1.0.2-tools.zip` 并完整解压。手机安装包单独下载，安装方法见 [安装说明](INSTALL.md)。制作工具运行在 Windows 电脑上，不在手机上转换视频。

Windows 10/11 64 位电脑需要先安装 Node.js，终端执行 `node --version` 应显示版本。本项目验证 Node.js 24.14.0。tools-r3 已内置 FFmpeg 9.0.1，无需另装 FFmpeg 或设置环境变量。

完整解压工具包，双击根目录 `Start-BelleWall.cmd`，看到网址后，用电脑浏览器打开 `http://127.0.0.1:8765`。制作期间不要关闭启动窗口；完成后按 Ctrl+C 关闭服务。服务仅监听本机，无需注册账号或上传到网站。

不要单独移动启动文件，也不要删除 `ffmpeg` 文件夹。内置转换器用于本地视频解码和图片集输出；如果遇到其不支持的编码，可先把素材转为 H.264 MP4。

### 进阶：使用自己的 FFmpeg

默认无需操作。如需替换内置转换器，在工具包根目录打开 PowerShell：

```powershell
$env:FFMPEG_BIN = 'C:\Tools\ffmpeg\bin'
node .\prototype\tools\sywp-webui.cjs
```

`FFMPEG_BIN` 可指定程序文件或所在目录，并优先于内置版本；路径失效时请修正，或执行 `Remove-Item Env:FFMPEG_BIN` 后从同一终端重启。未指定时依次查找工具包的 `ffmpeg/bin`、`bin`、系统 PATH。源码开发环境还支持既有 build 目录。环境变量修改后必须关闭旧工具窗口并重启。

## 2. 选择素材

支持常见视频输入，如 MP4、WebM、MOV、MKV；能否解码还取决于 FFmpeg 支持。第一次可用工具包 `examples/demo.mp4` 熟悉流程。

Wallpaper Engine 的 MPKG 必须含有已经渲染好的视频入口。工具按包内实际入口判断，不只看 project.type。实时场景、粒子／模型场景或包含脚本的工程不等于视频；这类包须先在原工具中预渲染／录制成视频，再转换。不要仅将扩展名改成 MPKG。SWF 暂不支持。转换不会执行 MPKG 中的脚本。

## 3. 裁剪和设置

先用下面这组参数：180×320、10 fps、100 张、速度 1、铺满裁剪。它大约得到最多 10 秒的循环，实际长度受源素材限制。

| 参数 | 用途 |
|---|---|
| 宽／高 | 壁纸内容画布。当前手机视频接受 180×320 或 360×640；网页接受 180×320 |
| cover | 等比例铺满，超出边缘的部分裁掉；拖动水平／垂直位置选择保留区域 |
| contain | 等比例完整显示，空白用补边颜色填充 |
| stretch | 拉伸到画布，可能使人物变形 |
| 帧率 | 输出图片集的采样率；10／20／30 可选。1.0.2 视频测试包按此帧率、最高 30 fps 调度；旧版约 10 fps，实际帧率取决于手机性能 |
| 最多图片张数 | 限制长度和体积；循环秒数约等于实际张数÷输出帧率 |
| 速度 | 2 为加速，0.5 为减速；转换时重采样，手机不再叠加速度参数 |

图片集使用未压缩 RGB565。180×320 每张 115,200 字节，300 张约 33 MiB；360×640 是其四倍。先做短视频，在手机导入时选择有足够空间的 C、E 或 F 盘。单个 SYWP payload 上限 256 MiB，工具会拒绝超限结果。

格式可以表达横屏、其他比例和更高帧率，但当前手机播放器会拒绝尚不支持的尺寸／方向。不要把“电脑能生成”理解为“每台手机都兼容”。

## 4. 生成并导入

填写标题，点生成，等待出现下载链接并保存 `.sywp`。完整复制到手机 E 盘或文件选择器能访问的位置。

在 1.0.2 测试包中打开 BelleWall → 壁纸管理 → 导入壁纸包，选文件后再选 C／E／F 存储盘。列表显示每张壁纸所在盘；上次选择的存储盘会作为下次默认值。壁纸已选中但还没有启动。先点“预览壁纸”，确认画面；再点“启动动态壁纸”，第一次选“60 秒检查”，确认后等待准备完成。

准备绑定现有桌面页时会自动切页，此时不要打开拨号或其他应用。壁纸出现后可正常滑页、打开应用或锁屏。锁屏／桌面不可见期间暂停，返回桌面后恢复。

## 5. 日常使用与停止

确认短测正常后，可选择持续播放。从应用菜单重新打开 BelleWall，点“停止并恢复桌面”，即可停止并恢复背景。运行时壁纸管理不可用，更换壁纸前先停止。

删除壁纸在壁纸管理内完成，只删除所列盘符上的导入副本，不删除源 SYWP。旧版导入的 C 盘副本仍留在 C 盘；如需转到 E／F，先停止播放，再从原始 SYWP 重新导入并选择目标盘，确认新副本可用后删除旧副本。保留自制源文件，方便重新导入。

## 常见问题

- 无法启动制作工具：确认 Node 可用；端口被占用时关闭旧工具窗口，或设置 `$env:PORT='8766'` 后用对应网址。
- 提示找不到 FFmpeg：请完整解压 tools-r3，确认 `ffmpeg/bin/ffmpeg.exe` 存在；如设置过 `FFMPEG_BIN`，请检查它是否指向失效路径。原 tools.zip 的开发目录 ENOENT 问题已修复。
- 提示实时场景：先预渲染成视频，不能直接转换 scene／SWF。
- 手机提示包损坏：重新生成并完整复制，不要手工编辑二进制包。
- 手机提示不适用：检查尺寸与方向，先使用 180×320 竖屏。
- 导入后桌面没变化：导入只是选中，还需要点“启动动态壁纸”。
- 启动被来电／拨号窗口打断：等待自动恢复，解锁回桌面后重试；不要删除恢复记录。
