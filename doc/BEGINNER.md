# 新手教程：不写代码制作动态壁纸

## 1. 准备工具

下载 Release 的 `BelleWall-1.0.0-tools-r2.zip` 并完整解压。手机安装包单独下载，安装方法见 [安装说明](INSTALL.md)。制作工具运行在 Windows 电脑上，不在手机上转换视频。

电脑需要 Node.js 和 FFmpeg。本项目验证环境为 Node.js 24.14.0、FFmpeg 9.0.1；压缩包不捆绑这两个运行依赖。安装 Node 后，在终端执行 `node --version` 应显示版本。解压 FFmpeg，找到包含 `ffmpeg.exe` 的 `bin` 目录。

推荐把 FFmpeg 的完整 `bin` 目录复制到工具包根目录新建的 `ffmpeg` 文件夹中，最终应存在 `ffmpeg/bin/ffmpeg.exe`，然后双击 `Start-BelleWall.cmd`。工具也能自动查找 PATH 中的 FFmpeg。

也可以在工具包根目录打开 PowerShell，执行（替换成你的实际路径）：

```powershell
$env:FFMPEG_BIN = 'C:\Tools\ffmpeg\bin'
node .\prototype\tools\sywp-webui.cjs
```

看到网址后，用电脑浏览器打开 `http://127.0.0.1:8765`。FFMPEG_BIN 已设为系统环境变量时，也可双击根目录的 `Start-BelleWall.cmd`。制作期间不要关闭启动窗口；完成后按 Ctrl+C 关闭服务。服务仅监听本机，无需注册账号或上传到网站。

## 2. 选择素材

支持常见视频输入，如 MP4、WebM、MOV、MKV；能否解码还取决于 FFmpeg 支持。第一次可用工具包 `examples/demo.mp4` 熟悉流程。

Wallpaper Engine 的 MPKG 必须含有已经渲染好的视频入口。工具按包内实际入口判断，不只看 project.type。实时场景、粒子／模型场景或包含脚本的工程不等于视频；这类包须先在原工具中预渲染／录制成视频，再转换。不要仅将扩展名改成 MPKG。SWF 暂不支持。转换不会执行 MPKG 中的脚本。

## 3. 裁剪和设置

先用下面这组参数：180×320、10 fps、100 张、速度 1、铺满裁剪。它大约得到最多 10 秒的循环，实际长度受源素材限制。

| 参数 | 用途 |
|---|---|
| 宽／高 | 壁纸内容画布。当前手机视频接受 180×320 或 360×640；网页接受 180×320 |
| cover | 等比例铺满，超出边缘的部分裁掉；拖动水平／垂直位置选择保留区域 |
| contain | 等比例完整显示，空白用补边颜色填充 |
| stretch | 拉伸到画布，可能使人物变形 |
| 帧率 | 输出图片集的采样率；10／20／30 可选。当前手机供帧约 10 fps，提高素材帧率不会自动提高手机显示帧率 |
| 最多图片张数 | 限制长度和体积；循环秒数约等于实际张数÷输出帧率 |
| 速度 | 2 为加速，0.5 为减速；转换时重采样，手机不再叠加速度参数 |

图片集使用未压缩 RGB565。180×320 每张 115,200 字节，300 张约 33 MiB；360×640 是其四倍。先做短视频，避免占满手机 C 盘。单个 SYWP payload 上限 256 MiB，工具会拒绝超限结果。

格式可以表达横屏、其他比例和更高帧率，但当前手机播放器会拒绝尚不支持的尺寸／方向。不要把“电脑能生成”理解为“每台手机都兼容”。

## 4. 生成并导入

填写标题，点生成，等待出现下载链接并保存 `.sywp`。完整复制到手机 E 盘或文件选择器能访问的位置。

打开 BelleWall → 壁纸管理 → 导入壁纸包。看到成功提示后，壁纸已选中，但还没有启动。先点“预览壁纸”，确认画面；再点“启动动态壁纸”，第一次选“60 秒检查”，确认后等待准备完成。

准备绑定四页时会自动切页，此时不要打开拨号或其他应用。壁纸出现后可正常滑页、打开应用或锁屏。锁屏／桌面不可见期间暂停，返回桌面后恢复。

## 5. 日常使用与停止

确认短测正常后，可选择持续播放。从应用菜单重新打开 BelleWall，点“停止并恢复桌面”，即可停止并恢复背景。运行时壁纸管理不可用，更换壁纸前先停止。

删除壁纸在壁纸管理内完成，只删除导入副本，不删除源 SYWP。库使用 C 盘空间，即使源包放在 E 盘也是如此。保留自制源文件，方便重新导入。

## 常见问题

- 无法启动制作工具：确认 Node 可用；端口被占用时关闭旧工具窗口，或设置 `$env:PORT='8766'` 后用对应网址。
- 提示找不到 FFmpeg：工具包不附带 FFmpeg；按上文放到 `ffmpeg/bin/ffmpeg.exe` 即可。`FFMPEG_BIN` 支持程序文件或所在目录，显式设置后优先使用；路径已失效时请修正或删除该变量，关闭旧工具窗口并重新启动。原版出现开发目录 `spawnSync ... ENOENT` 时，请下载 tools-r2。
- 提示实时场景：先预渲染成视频，不能直接转换 scene／SWF。
- 手机提示包损坏：重新生成并完整复制，不要手工编辑二进制包。
- 手机提示不适用：检查尺寸与方向，先使用 180×320 竖屏。
- 导入后桌面没变化：导入只是选中，还需要点“启动动态壁纸”。
- 启动被来电／拨号窗口打断：等待自动恢复，解锁回桌面后重试；不要删除恢复记录。
